The short version

It records your screen. So the rules are strict.

Everything stays on your machine unless you move it yourself. The recorder has no network code, no accounts and no telemetry.

What it stores

Screenshots when the screen changes, the text recognized in them, and which application and window were in front. All in a folder you can open, move or delete.

Excluded before it is saved

Exclusion rules are checked before anything is written. A monitor is skipped entirely if any visible window on it matches, not just the one in front. Password managers and private browser windows are excluded by default.

Never hidden

rsrewind status always says whether it is recording. There is no stealth mode, under any flag.

Deletion is real

rsrewind forget removes screenshots, recognized text and window titles together, and overwrites deleted database pages. Uninstalling never deletes your history behind your back.

Quiet logs

Logs hold counts, ids and rule names. Screen text and window titles are never logged at normal levels.

You control copies

Exporting to another machine is always a command you run. Deleting on one machine does not reach copies you already moved.

Known gaps in this release

  • Recorder privacy gaps from an independent review are not fixed yet (how it proves a frame was checked, how it behaves when window information is unreadable, and how pausing is acknowledged). Until they are, treat it as unsuitable for sensitive desktops.
  • No encryption at rest. Anyone who can read your data folder can read your history.
  • Imported files are not authenticated, only checked for damage.

The complete policy, including logging and deletion details, is in PRIVACY.md. Report a security problem as described in SECURITY.md.
