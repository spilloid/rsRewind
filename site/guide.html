Your first few minutes

See it work, then make it yours.

Start small: record something harmless and find it again. Everyday use needs no command line on Windows, Mac or Linux: the window and the icon next to the clock do the work.

Start with a harmless test session. This is an early release with unencrypted history and known privacy gaps. Read what gets recorded before using it on your everyday desktop.

Make your first searchable moment

  1. Install for your platform and open rsRewind from your search or application menu. It starts the tray icon and, by default, recording.
  2. Check the icon next to the clock: red means recording (on Windows and Linux, green means not; on the Mac the symbol changes with the state). If it is not recording, choose Start recording in the window. On the Mac, grant Screen Recording permission when asked and reopen the app if macOS asks you to.
  3. Open a text document containing a distinctive phrase, such as violet bicycle. Keep it visible briefly, then switch back.
  4. Allow a little time for recognition. Search for the phrase in rsRewind and select a result. You should see the screenshot containing your text.
  5. Stop recording using the recorder controls when your test is done.

Look around your history

Find

Search words you remember. Select a result to jump to its moment. Windows and Linux use Ctrl + F to focus search; Mac uses Command + F. The / key also focuses search when you are not typing in a field.

Browse

Move earlier or later through the timeline. Filter to a computer when you have imported history from several machines.

Inspect

Double-click a screenshot for the full viewer. Zoom, pan and step through nearby moments to recover the context.

The window is the same on every platform: search, the timeline, the navigator with marks and keyframes, the screenshot viewer, and multi-select with export. Press M to mark a moment; use [ and ] to step between marks and , and . between keyframes.

Stay in control

The tray icon (Windows, Linux) or menu-bar item (Mac) shows the recorder state and offers pause, resume, forget and stop controls. Closing the history window does not stop the background recorder, but choosing Quit from the tray or menu-bar icon does: it stops recording and removes the icon, so recording never runs without an icon showing it. Check the icon when you finish.

Defaults retain 90 days with a 50 GB soft storage limit. History survives uninstalling the app. Privacy exclusions are configurable, but known enforcement gaps remain; use a session you are comfortable recording.

Start at login, or turn that off

Use the first-run login option where offered, or run rsrewind tray --autostart on. Use --autostart off to disable future login startup. Turning it off does not stop a running recorder or delete history. On the Mac the command is /Applications/rsRewind.app/Contents/MacOS/rsrewind tray --autostart on; it writes a per-user LaunchAgent. See the Mac reference.

Find your files and change settings

rsrewind data-dir prints the folder holding your history and config.toml. Defaults are %LOCALAPPDATA%\rsRewind on Windows, ~/.local/share/rsRewind on Linux (unless XDG_DATA_HOME is set), and ~/Library/Application Support/rsRewind on Mac.

If your first test does not appear

No screenshots yet

Check that recording is running, not paused. Try changing the visible screen. Idle, lock and exclusion rules can prevent capture. Run rsrewind doctor for diagnostics. On Mac, check screen-recording permission and restart the app if requested.

Pictures appear, but search finds nothing

Text recognition runs in the background; allow it time and try a clear, large text phrase. On Linux, install Tesseract and restart the recorder. On Windows, doctor checks whether an OCR language is available. On the Mac, text recognition uses Apple Vision on device and needs nothing extra.

I want to remove recent history

Use the tray or menu-bar forget action and confirm it, or rsrewind forget 15m --yes. This removes recent history from the active store. It does not erase backups, exports or copies held elsewhere. Read deletion limits.

Still stuck? Report an issue with your platform and diagnostic status. Do not attach private screenshots or captured text.
