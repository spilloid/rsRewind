Windows 11 · x64

The signed installer installs for your user account without administrator rights.

Download Windows installerPortable ZIP
  1. Download and verify the installer using the checks below.
  2. Run the installer, then open rsRewind from the Start menu.
  3. Choose Start recording and follow the first-run guide.
  4. Look for the rsRewind icon in the notification area (red while recording, green when not). Windows may keep it in the hidden-icons overflow next to the clock; drag it out to keep it visible. Right-click it to pause, resume, forget recent history or open the window.
Verify the download before installing

Download SHA256SUMS.txt into the same folder. In PowerShell:

Get-FileHash .\rsrewind-v0.1.0-x64.msi -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
Get-AuthenticodeSignature .\rsrewind-v0.1.0-x64.msi | Format-List Status,SignerCertificate

The hash must match its line. Signature status must be Valid, with signer CN=Joseph Spillers. If checks fail, do not run it. For the portable ZIP, verify the ZIP hash and the signature of the extracted executable.

Portable use and diagnostics

Extract the ZIP, then run the executable with ui to open the viewer. For the installed version, use:

& "$env:LOCALAPPDATA\Programs\rsRewind\rsrewind.exe" doctor
& "$env:LOCALAPPDATA\Programs\rsRewind\rsrewind.exe" ui

Windows 10 is unverified. The app does not require a browser runtime.

Linux · KDE Plasma 6 on Wayland

The x86-64 recorder requires Plasma on Wayland. Other desktops can browse and search imported history. Install Tesseract from your distribution for text recognition.

Download Linux AppImageTarballChecksums

Save the AppImage and SHA256SUMS.txt in the same folder, then verify and run it:

sha256sum --check --ignore-missing SHA256SUMS.txt
chmod +x rsrewind-v0.1.0-linux-x86_64.AppImage
./rsrewind-v0.1.0-linux-x86_64.AppImage

Confirm the file reports OK first. The first run copies rsRewind to ~/.local/share/rsRewind-app/ and adds rsRewind to your application menu, so the tray icon and recorder keep running after the window closes and KDE can recognise the program. From then on, search for rsRewind in KRunner or the application menu: it brings up the tray icon, starts recording (unless you turned that off) and opens the window. The red or green icon in the system tray shows whether it is recording.

Enable text recognition and login startup
sudo apt install tesseract-ocr   # Debian / Ubuntu
# Fedora Atomic / Bazzite instead: rpm-ostree install tesseract (then reboot)
~/.local/share/rsRewind-app/rsrewind doctor
~/.local/share/rsRewind-app/rsrewind tray --autostart on

Restart the recorder after installing Tesseract. Existing moments are read in the background. Autostart starts the tray and recorder at login. To stop recording from starting by itself, set record_on_launch = false under [capture] in config.toml. A newer AppImage refreshes the copy the next time you run it.

Using the tarball instead
tar -xzf rsrewind-v0.1.0-linux-x86_64.tar.gz
mkdir -p ~/.local/bin
install -m 755 rsrewind-v0.1.0-linux-x86_64/rsrewind ~/.local/bin/rsrewind
~/.local/bin/rsrewind launch

The first launch adds the application-menu entry and icon.

Permissions and removing it

The recorder writes ~/.local/share/applications/rsrewind-recorder.desktop, which KWin uses to authorize capture. Removing it withdraws that authorization. For a supervised user service instead of tray startup, see the development reference. Avoid configuring two startup mechanisms. To remove the program, run rsrewind tray --autostart off, then delete ~/.local/share/rsRewind-app/ and ~/.local/share/applications/rsrewind.desktop. Your history in ~/.local/share/rsRewind is never deleted by removing the program.

Mac · Apple Silicon preview

macOS 14 or newer, ARM64. Interactive capture, permissions, menu layout and sleep/wake still need real-Mac acceptance.

Development preview, not notarized. The app is ad-hoc signed; it has no Developer ID signature or notarization. There is no Intel build. macOS may block opening it.

Download Mac disk imageChecksums
  1. Download the disk image and SHA256SUMS.txt into the same folder, then verify it below.
  2. Open the disk image and drag rsRewind to Applications.
  3. Open the app. Grant screen-recording permission in System Settings → Privacy & Security when requested, restarting if macOS asks. Choose Start recording for a harmless test.
Verify, diagnose and understand preview limits
shasum -a 256 -c SHA256SUMS.txt 2>/dev/null | grep rsrewind-v0.1.0-macos-arm64.dmg
/Applications/rsRewind.app/Contents/MacOS/rsrewind doctor

A matching checksum checks file integrity, not a verified publisher identity. If macOS blocks the app, treat that as a development-distribution limitation; review the source and build provenance before deciding to run it. Permission settings may be called Screen Recording or Screen & System Audio Recording depending on macOS version.
