Windows 11 · x64

The signed installer installs for your user account without administrator rights, adds rsRewind to the Start menu and starts it at login.

Download Windows installerPortable ZIPChecksums
  1. Download the installer and verify it using the checks below.
  2. Run the installer, then open rsRewind from the Start menu.
  3. Choose Start recording and follow the first-run guide.
  4. Look for the rsRewind icon in the notification area (red while recording, green when not). Windows may keep it in the hidden-icons overflow next to the clock; drag it out to keep it visible. Right-click it to pause, resume, forget recent history or open the window.
Verify the download before installing

Download SHA256SUMS.txt into the same folder. In PowerShell:

Get-FileHash .\rsrewind-v0.2.0-x64.msi -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
Get-AuthenticodeSignature .\rsrewind-v0.2.0-x64.msi | Format-List Status,SignerCertificate

The hash must match its line. Signature status must be Valid, with signer CN=Joseph Spillers. If checks fail, do not run it. For the portable ZIP, verify the ZIP hash and the signature of the extracted executable.

Portable use and diagnostics

Extract the ZIP, then run the executable with ui to open the viewer. For the installed version, use:

& "$env:LOCALAPPDATA\Programs\rsRewind\rsrewind.exe" doctor
& "$env:LOCALAPPDATA\Programs\rsRewind\rsrewind.exe" ui

Windows 10 is unverified. The app does not require a browser runtime.

Mac · macOS 14+ · Apple Silicon

A native app for Apple Silicon Macs (M1 and later). It records with ScreenCaptureKit, recognises text with Apple Vision, and puts a menu-bar item next to the clock. There is no Intel build.

Download Mac disk imageChecksums
  1. Download the disk image and SHA256SUMS.txt into the same folder, then verify the image (below).
  2. Open the disk image and drag rsRewind to Applications.
  3. Open the app. The first time, macOS may say it cannot verify the developer: the app is signed, but not with an Apple Developer ID and not notarized. Right-click (Control-click) the app and choose Open, or allow it under System Settings → Privacy & Security → Open Anyway.
  4. Grant Screen Recording permission in System Settings → Privacy & Security when asked (called Screen & System Audio Recording on some versions) and reopen the app if macOS asks. The recorder cannot and does not bypass a denied permission.
  5. Choose Start recording for a harmless test. The menu-bar icon turns red while recording, uses a different symbol for each state (recording, paused, stopped, unknown) and turns orange when privacy rules are not being enforced; its menu offers pause, resume, forget and Quit, which stops recording.
Verify the download
shasum -a 256 -c SHA256SUMS.txt 2>/dev/null | grep rsrewind-v0.2.0-macos-arm64.dmg

The line must end in OK. A matching checksum confirms the file is the one the release workflow produced; it does not replace the publisher identity a notarized app would carry. Verify before you bypass Gatekeeper, not after.

Command line, login startup and removing it

The command-line tool is the executable inside the app. Keep the app in Applications so login startup and assistant connections keep pointing at it:

/Applications/rsRewind.app/Contents/MacOS/rsrewind doctor
/Applications/rsRewind.app/Contents/MacOS/rsrewind status
/Applications/rsRewind.app/Contents/MacOS/rsrewind tray --autostart on

Autostart writes a per-user LaunchAgent to ~/Library/LaunchAgents/ that brings up the menu bar and recorder at login; --autostart off removes it. History lives in ~/Library/Application Support/rsRewind. To remove rsRewind, turn autostart off, choose Quit in the menu bar, and move the app to the Trash. Your history folder is never deleted by removing the app.

Linux · KDE Plasma 6 on Wayland · x86-64

Recording needs Plasma on Wayland, where KWin provides screenshots and the window list rsRewind's privacy rules depend on. Every other desktop can run the window, the command line and import history. Install Tesseract from your distribution for text recognition.

Download Linux AppImageTarballChecksums

Save the AppImage and SHA256SUMS.txt in the same folder, then verify and run it:

sha256sum --check --ignore-missing SHA256SUMS.txt
chmod +x rsrewind-v0.2.0-linux-x86_64.AppImage
./rsrewind-v0.2.0-linux-x86_64.AppImage

Confirm the file reports OK first. The first run copies rsRewind to ~/.local/share/rsRewind-app/ and adds rsRewind to your application menu, so the tray icon and recorder keep running after the window closes and KDE can recognise the program. From then on, search for rsRewind in KRunner or the application menu: it brings up the tray icon, starts recording (unless you turned that off) and opens the window. The red or green icon in the system tray shows whether it is recording.

Enable text recognition and login startup
sudo apt install tesseract-ocr   # Debian / Ubuntu
# Fedora Atomic / Bazzite instead: rpm-ostree install tesseract (then reboot)
~/.local/share/rsRewind-app/rsrewind doctor
~/.local/share/rsRewind-app/rsrewind tray --autostart on

Restart the recorder after installing Tesseract. Existing moments are read in the background. Autostart starts the tray and recorder at login. To stop recording from starting by itself, set record_on_launch = false under [capture] in config.toml. A newer AppImage refreshes the copy the next time you run it.

Using the tarball instead
tar -xzf rsrewind-v0.2.0-linux-x86_64.tar.gz
mkdir -p ~/.local/bin
install -m 755 rsrewind-v0.2.0-linux-x86_64/rsrewind ~/.local/bin/rsrewind
~/.local/bin/rsrewind launch

The first launch adds the application-menu entry and icon.

Permissions and removing it

The recorder writes ~/.local/share/applications/rsrewind-recorder.desktop, which KWin uses to authorize capture. Removing it withdraws that authorization. For a supervised user service instead of tray startup, see the development reference. Avoid configuring two startup mechanisms. To remove the program, run rsrewind tray --autostart off, then delete ~/.local/share/rsRewind-app/ and ~/.local/share/applications/rsrewind.desktop. Your history in ~/.local/share/rsRewind is never deleted by removing the program.
