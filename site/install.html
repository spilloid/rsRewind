Install

Two downloads, both signed. The installer is per-user and needs no administrator rights.

Installer (.msi) Portable (.zip) SHA256SUMS.txt

This is a pre-release, so GitHub's "latest release" button will not show it. Use the links above.

Verify before you run it

rsRewind records your screen, so check what you downloaded. In PowerShell, in the folder you saved the files to:

Get-FileHash .\rsrewind-v0.0.3-x64.msi -Algorithm SHA256
Get-Content .\SHA256SUMS.txt          # the hash above must match its line

Get-AuthenticodeSignature .\rsrewind-v0.0.3-x64.msi | Format-List Status,SignerCertificate

Status must be Valid and the signer CN=Joseph Spillers, with a Microsoft timestamp. The same applies to rsrewind.exe inside the zip. If either check fails, do not run it, and please open an issue.

First run

  1. Install. The installer puts rsrewind.exe in %LOCALAPPDATA%\Programs\rsRewind. With the zip, put the exe wherever you like.
  2. Check the setup. rsrewind doctor reports whether capture works, whether Windows text recognition has a language installed, and how much disk is free.
  3. Record. rsrewind start, work normally for a few minutes, then rsrewind status.
  4. Look back. rsrewind ui opens the rewind room. Search at the top; click a result to jump to that moment.

History lives in %LOCALAPPDATA%\rsRewind. Uninstalling never deletes it. To delete recent history, use rsrewind forget 15m --yes; it removes the screenshots, the recognized text and the window titles together.

Good to know

Idle means paused

After five minutes without input nothing new is stored. Change idle_after_secs in config.toml if you want otherwise.

Privacy exclusions

Password managers and private browser windows are excluded by default. A monitor is skipped entirely if any visible window on it matches. Details.

Disk use

Defaults keep 90 days and cap storage at 50 GB. Both are settings, and rsrewind doctor warns when space is tight.
