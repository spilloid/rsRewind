# Licensing

rsRewind is MIT-licensed (`LICENSE`). This file is the policy for everything else it builds with, ships or runs,
and the record of how each obligation is met. Last reconciled 2026-10-10.

## Policy

1. **Linked or bundled code must be permissive.** Allowed: MIT, Apache-2.0 (with or without LLVM exception), BSD-2/3,
   ISC, Zlib, BSL-1.0, Unlicense, CC0-1.0, 0BSD, Unicode-3.0 (the list in `deny.toml`). Where a crate offers a choice
   (`MIT OR Apache-2.0 OR LGPL-2.1-or-later`), rsRewind takes the permissive option. No copyleft code is linked.
2. **Every release carries the notices.** `THIRD-PARTY-NOTICES.html` is generated by `cargo about` from the exact
   dependency graph of the release build and goes into the ZIP, the Linux tarball and the MSI install folder.
3. **CI enforces it.** `cargo deny check licenses` fails any pull request that adds a dependency under a license not on
   the list, or one it cannot identify.
4. **External programs are not dependencies.** rsRewind may run programs the user installed (Tesseract); it does not
   link or ship them. If that ever changes, their licenses join rule 2 before the release, not after.
5. **Data files are licensed separately from code.** Models, fonts and artwork are checked for their own terms before
   they are embedded or shipped.

## What is in a release, and what it owes

| Component | How it gets in | License | Obligation and where it is met |
|---|---|---|---|
| Rust crates (~470) | statically linked | permissive, per crate | copyright + license text: `THIRD-PARTY-NOTICES.html` |
| libwebp (Google), C | compiled from source vendored in `libwebp-sys` | BSD-3-Clause | notice + disclaimer: added to the notices file via `deny.toml` / `about.toml` clarification (the wrapper crate itself declares only MIT) |
| SQLite, C | compiled from source (`libsqlite3-sys`, `bundled`) | public domain | none (credited in the notices file) |
| `Iced-Icons.ttf` | embedded by `iced_graphics` | MIT (part of the crate) | covered by the crate's notice |
| Fira Sans | not compiled in (`iced` feature `fira-sans` off; verified absent from the binary 2026-10-10) | SIL OFL 1.1 | none while off; re-check if the feature is enabled |
| rsRewind artwork (`assets/icon`, `assets/tray`) | embedded in the tray | supplied by the maintainer (2026-10-09), distributed under the project's MIT license | none beyond `LICENSE` |

## Run, not shipped

| Program | Used for | License | Notes |
|---|---|---|---|
| Tesseract (`tesseract` on PATH) | text recognition on Linux | Apache-2.0; language data (`tessdata`, `tessdata_fast`) Apache-2.0; Leptonica BSD-2-style | the user installs it from their distribution; rsRewind invokes it as a child process. Bundling it later would require its license texts and Leptonica's in the notices and a changelog note. |
| Windows.Media.Ocr | text recognition on Windows | part of Windows | OS API |
| KWin, the Wayland compositor | screenshots, window list on Plasma | part of the desktop | D-Bus calls |

## Considered and not used

- `ocrs` models (CC-BY-SA-4.0, trained on HierText): evaluated 2026-10-10 and dropped for accuracy (see
  `crates/rsrewind-ocr/src/tesseract.rs`), so no share-alike data ships.

## Regenerating and checking

```sh
cargo deny check licenses                                  # the CI gate
cargo about generate about.hbs -o THIRD-PARTY-NOTICES.html # what a release ships
```
